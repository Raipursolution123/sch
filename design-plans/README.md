# Design plans

Output directory for `/improve-ui` audits on School ERP.

- Agents **must not** edit product source while auditing.
- Write one plan file per accepted finding (see
  `.cursor/skills/improve-ui/references/plan-template.md`).
- A separate implementation agent (or human) executes the plan.

Suggested filename: `YYYY-MM-DD-<surface>-<short-slug>.md`
